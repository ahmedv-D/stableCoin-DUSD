# DUSD V0.5.1 — Implementation Report

Status: **reference-simulator prototype, testnet-evaluation ready**. NOT a
mainnet deployment; NOT a production claim. Every number below is produced by
the REAL engine (`core/dusd_v051_state.py`) via read-only harnesses — no
synthetic field writes, no invented symbols, engine byte-identical
throughout.

## 1. What was actually built

- `core/dusd_v051_state.py` — the DVM-BASIC-shaped V0.5.1 state machine:
  ring-signed mint (`deposit_and_mint`), TWAP/spot primitives
  (`record_spot`, `twap`), RSWAP-priced DER0/DUSD swaps with `SWAP_FEE`
  (0.30%), insured redemption (`redeem` with claim-factor haircut),
  period advance, POL/insurance accounting, uint64-atom conservation
  guarantees.
- `tests/` — the green harnesses (all audit the engine's own getters):
  `test_dusd_v051.py` (11 unit tests), `test_adversarial_v051.py` (26
  tests), `test_properties.py` (Monte-Carlo 60k), `test_crash_matrix.py`
  (36-cell adversarial cross-check), `test_fuzz.py` / `test_fuzz_v051.py`
  (102,400-op fuzz), plus 12 closure tests in `v0.5/attack/`.

## 4. Engine surface that stays authoritative

Initialisation/spot: `record_spot`, `twap`, `eligible_collateral`,
`backing_nav`, `coverage`, `claim_factor`. Mint/swap/redemption:

oracle (quote integrity) and wallet custody are NOT claimed for this
reference model — see `docs/V0.5.1-THREAT-MODEL.md` and the committed
`docs/V0.5.1-ADVERSARIAL-RESOLUTION.md` for the honest residual-risk list
and the `POL-MINT-SHARE`/`MIN_COVERAGE` enforcement boundary.
