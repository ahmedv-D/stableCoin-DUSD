## Repository baseline reviewed

## Crash stress matrix

Using a stressed state near 1.22x initial coverage and reducing the internal risk price:

| DERO risk-price drop | Claim factor |
|---:|---:|

This demonstrates the intended limitation: the model provides proportional pari-passu claims under severe DERO impairment; it does not create a guaranteed external $1 redemption reserve.

## Open risks that remain

1. DVM-BASIC exact asset-input semantics are not proven here.
2. Real DERO custody behavior is not proven here.
3. DUSD retirement/burn semantics are not proven here.
4. uint64-safe production arithmetic still requires VM-specific implementation and boundary tests.
5. Governance/quorum is intentionally not finalized.
6. TWAP half-life/window and spot/TWAP arbitrage parameters remain governance decisions.
7. Active-backer fee entitlement/claim implementation is not yet a production storage model.
8. Liquidation of vault collateral on DERO must be specified at VM transaction level.
