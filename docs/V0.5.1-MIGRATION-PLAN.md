# V0.2.1 → V0.5.1 Migration Plan

## Preserve

- repository history and original V0.2.1 contract
- documentation of testnet-required assumptions
- DERO DVM-BASIC target environment

## Replace economically

- fixed `REDEEM_RATIO=100`
- vault-local redemption as the sole claim mechanism
- collateral-only backing
- owner-only emergency as production governance

with:

- dynamic redemption
- unified backing claim
- POL + Insurance + eligible collateral
- internal TWAP risk pricing
- provenance-aware collateral eligibility
- explicit insurance/backstop accounting

## Sequence

1. Add V0.5.1 economic spec.
2. Add simulator/state machine.
3. Port invariant tests.
4. Add adversarial/fuzz/Monte Carlo tests.
5. Port only tested primitives into DVM-BASIC.
6. Validate exact DVM asset and custody semantics on testnet.
7. Re-run adversarial suite against the DVM implementation.
8. Governance/quorum review.
9. Only then consider mainnet deployment.

## Do not do yet

- mainnet deploy
- external price oracle dependency for core pricing
- fixed DERO/DUSD redemption guarantee
- direct re-use of POL-origin DERO as fresh collateral
- marketing the system as fiat-redeemable under arbitrary DERO collapse
